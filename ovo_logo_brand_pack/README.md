## Kullanım

```html
<img src="/logo-neon-on-black.svg" alt="OVO">
```

Favicon:

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
```

Renk değiştirmek için en esnek dosya:

```html
logo-currentColor.svg
```

Bunu inline SVG olarak kullandığında CSS `color` değeriyle renk yönetebilirsin.
