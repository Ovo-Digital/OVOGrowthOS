# Scenario engine

A scenario belongs to an evaluation and persists revenue, margin, advertising, return, AOV/customer, variable-cost, internal-cost, setup, contract, baseline, commission-model, and tier assumptions. Calculation is backend-authoritative and returns financial waterfall, commission breakdown, brand contribution, OVO margin, break-even MER, allowable ad spend, setup payback, warnings, and risk level.

Users can save, duplicate, rename, mark one preferred, compare, and delete scenarios. Scenario outputs are recalculated when saved; they do not alter the frozen evaluation recommendation.
