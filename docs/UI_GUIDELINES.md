# UI guidelines

The interface uses a restrained commerce-admin visual language: warm grey canvas, white cards, compact tables, subtle borders, semantic badges, dense navigation, and minimal elevation. It does not use Shopify assets or proprietary code.

Green is positive, yellow is conditional, red is risk/loss, blue is informational, and grey is neutral. Money is formatted for `tr-TR` with TRY while API payloads remain invariant JSON decimals. Desktop is primary and the shell collapses below 900px.
